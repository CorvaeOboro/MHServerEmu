Stash Affinity

items sort into named stash tabs

When you right-click an item in your inventory while a stash is open , the server normally drops it into the currently viewed tab . the vanilla game already has Affinity for character stash tabs , this mod adds more affinities per item types , based on the name of the stash tab .

  • Character-bound and avatar-restricted items go to that hero's personal stash first.
  • If the item is not character-specific, it is matched by type to a tab whose custom name contains the affinity keyword.
  • If the matching tab is missing, full, or cannot accept the item, it falls back to the tab the client originally requested.
