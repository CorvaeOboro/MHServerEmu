Death Recap

shows top damage sources in chat on death

When your avatar dies , the server sends a formatted death recap to your chat window , showing the top damage sources moments before death . Damage sources are sorted by total damage , with shortened names , abbreviated damage values , and damage type labels . Incursion enemies show their display name ( e.g. "CaptainAmerica Invader" ) instead of the raw prototype name .

Output Formats

Single-line (default)

A concise one-line summary with top damage sources , shortened names , k-abbreviated damage , and damage type labels .

DEATH = Sca 8k E | Ven 3k P | Lok 2k M

Commands

CommandDescription
!recapRe-display your last death recap in chat ( useful after respawning )

Config Options

OptionDefaultDescription
DeathRecapEnabletrueMaster switch
DeathRecapMaxEvents20Circular buffer capacity per avatar ( how many recent events to retain )
DeathRecapTopN3How many top damage sources to list in the recap
DeathRecapNameLength3Max letters for shortened source names ( e.g. 3 = "Sca" )
DeathRecapDamageTypeLength1Max letters for damage type label ( e.g. 1 = "P" , 3 = "Phy" )
DeathRecapLoggingEnablefalseDebug logging to server console
