Area Notes

place labelled map pins at world positions for area design

Area Notes is a dev tool for marking world positions with labelled pins . Each note captures a position , category , and optional comment , and spawns an invisible nameplate marker in-world so the label is visible while editing . Notes can be flushed to JSON for use by other tools ( enemy placement , event design , etc. ) .

Requires admin privileges . All note commands are gated on AccountUserLevel.Admin .

Commands

CommandDescription
!note place <category> [comment...]Place a note at your current position . Categories : boss , mob , miniboss , or any custom word . Example : !note place boss good spawn for vampire lord
!note listList all notes in the current region with labels , categories , positions , and comments
!note clearClear all notes in the current region and despawn their markers
!note remove <label>Remove a specific note by label ( e.g. NOTE_BOSS_01 ) and despawn its marker
!note saveFlush all notes to a JSON file in Logs/AreaNotes/
!note statusShow a summary of all placed notes across all regions
!note clearallClear ALL notes across all regions and despawn their markers ( admin only )

Note Labels

Notes are auto-labelled with an incrementing per-region , per-category counter :

NOTE_BOSS_01
NOTE_BOSS_02
NOTE_MOB_01
NOTE_MINIBOSS_01

JSON Export

!note save writes a timestamped JSON file to Logs/AreaNotes/ with the following structure :

{
  "exportedAt": "2026-08-01T15:30:00",
  "totalNotes": 1,
  "regions": [
    {
      "region": "Entity/Regions/AvengersTowerHUB.prototype",
      "regionId": 12345,
      "notes": [
        {
          "label": "NOTE_NPC_01",
          "category": "npc",
          "position": { "x": -98.75, "y": 268.75, "z": 177.0 },
          "comment": "Herald of Darkness spawn - next to event vendor machine downstairs to the left",
          "timestamp": "2026-08-01T15:25:00"
        }
      ]
    }
  ]
}

In-World Markers

Each note spawns an invisible avatar-rendered proxy entity at the noted position . The proxy displays the note label as a red prestige nameplate ( level 5 ) with no visible 3D model . Markers are untargetable , non-hostile , and have AI disabled .
