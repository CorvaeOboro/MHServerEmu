Loot Filter

item filtering expanded

adds rarity-based item filtering for additional item types , per-player character settings , set via chat commands.

Filtered Item Types

Ring , Medal , Insignia , Team-Up Gear , Catalyst , Uru-Forged

Items at or below the configured rarity are discarded ( unlike vaporizer , no credits, no Pet XP ).

Commands

CommandDescription
!filter listShow current thresholds for your character
!filter set <type> <rarity|on/off> [global|me|<character>]Set a filter
!filter clear <type> [global|me|<character>]Remove a filter setting
!filter clearallRemove all settings
!filter raritiesList valid rarity names ( common , uncommon , rare , epic , cosmic )

Examples

CommandDescription
!filter set teamup epicdiscards team-up drops at epic or below , across all characters
!filter set ring uncommon mediscards ring drops at uncommon or below , for the current character only
!filter set uruforged ondiscards all uru-forged drops , across all characters
!filter clear ring globalremove the global ring threshold
since teamup gear is always lvl1 , it makes since to set a global filter , for most other items its better to set character specific filters using "me" as the target if currently playing them or by name . this way when you switch to playing a lower level character you can iterate up the rarity filter on them . most uruforged items may be purchased in avengers hub so setting the filter to "on" to discard them all .

Character-Specific Mode

With LootFilterCharacterSpecificEnable=true , hero-specific gear for OTHER characters is filtered out . so only see drops meant for your current hero plus any-hero items . this is prefered for a Self-found like experience , where you only progress character specific uniques when playing that character.

Saved Settings

Settings are saved per player to server in Data/PlayerLootFilters/<playerId>.json , so that they are easily human editable , and potential for editing externally thru a tool if the LootFilter becomes more specific

Config Options
